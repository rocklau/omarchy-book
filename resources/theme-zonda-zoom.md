# Omarchy Zonda Zoom 主题（DHH 官方）

- 仓库：<https://github.com/dhh/omarchy-zonda-zoom-theme>
- 一句话：DHH 出品的 Omarchy 主题，灵感来自帕加尼 Zonda HH——碳黑底、暖象牙文字、哑钢表面、冰蓝点缀。

## 安装

```bash
omarchy theme install https://github.com/dhh/omarchy-zonda-zoom-theme
```

## 配色

| 角色 | Hex |
|---|---|
| 背景 Background | `#141313` |
| 深背景 Dark background | `#0f0e0e` |
| 更深背景 Darker background | `#0a0a0a` |
| 浅背景 Lighter background | `#2c2b2b` |
| 前景 Foreground | `#F6F4EC` |
| 强调 Accent | `#6b7fbe` |
| 选区 Selection | `#384873` |
| 弱化 Muted | `#a39c9c` |

完整 ANSI 色板见仓库 `colors.toml`；图标集为 `Yaru-blue`。
